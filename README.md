# pypacctoolbox
(Py)thon  (P)article (Acc)elerator (Toolbox) = pypacctoolbox for teaching accelerator physics. Gathers many text book equations and ideas in a format easy for a graduate student to use in exploring concepts in accelerator science. Might be useful for those wishing to create introductory plots for their reports of theses.

Design philosphy
* Classes + with sympy variables

Depenencies
* matplotlib
* sympy
* juypter
